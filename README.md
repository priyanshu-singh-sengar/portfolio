# Priyanshu Singh | Developer Portfolio

Welcome to the repository for my personal portfolio! This is a modern, highly responsive, and interactive single-page application built to showcase my skills, projects, and experiences as a Backend & Full-Stack Engineer.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS3 (Custom Glassmorphism & Dark Theme)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Deployment**: Ready for Vercel / Netlify

## ✨ Features

- **Modern Aesthetics**: A sleek dark mode UI utilizing custom CSS glassmorphism, glowing gradient orbs, and micro-animations.
- **Dynamic Typing Effect**: A custom React hook that powers the self-erasing and re-typing subheadline.
- **Scroll Reveal Animations**: Implementation of the `IntersectionObserver` API to smoothly fade elements into view as you scroll down the page.
- **Fully Responsive**: Carefully designed layouts (including mobile hamburger menus and responsive grids) that work flawlessly on everything from 4K monitors to smartphones.
- **Embedded Resume**: A dedicated section to view the PDF resume seamlessly directly on the site.

## 💻 Getting Started Locally

If you'd like to clone this repository and run it on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/priyanshu-singh-sengar/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser.

## 📦 Building for Production

To build the app for production (this will generate an optimized `dist` folder):
```bash
npm run build
```

## 🌐 Deployment (Vercel)

This project is fully configured and ready to be deployed on Vercel. 
1. Push your code to a GitHub repository.
2. Log into [Vercel](https://vercel.com/) and click "Add New Project".
3. Import your GitHub repository. Vercel will automatically detect that it's a **Vite** project and configure the build settings for you (`npm run build`, outputting to `dist`).
4. Click Deploy!
